# Not Slacking Bot (Kaiman's Bot)

A fun and simple Slack bot built for the Hack Club Stardance Challenge (https://stardance.hackclub.com/missions/slack-bot). This bot was created to bring some entertainment to the workspace with quick jokes and fun facts!

## Features

Currently, the bot supports the following slash commands:

* **`/kaimans-bot-joke`**: Tells a very funny joke!.
* **`/kaimans-bot-catfact`**: Delivers a random, interesting fact about cats.
* **`/kaimans-bot-ping`**: Pings the bot to check if it's online and runs a sample command.

*(More features utilizing free APIs are planned for the future.)*

## Built With

* **Slack API / Bolt:** For the core bot functionality and slash command integration.
* **VS Code:** The primary development environment.
* **Hack Club Guides:** Built following the official Hack Club Slack bot tutorial.

## Getting Started

If you are part of the Hack Club Slack workspace, you can try out the bot yourself! 
1. Navigate to the `#bot_spam` channel.
3. Type `/kaimans` in the message box to see the autocomplete list of all available commands.
4. Hit enter to run one and see the bot in action!

## Background & Journey

This project was my very first time making a Slack bot. While following the guide, being new to VS Code and dealing with SSH configurations made it challenging to understand what was going on at first. However, my interest pushed me to stick with it! 

I managed to get everything working by troubleshooting errors with AI and getting amazing help from the Hack Club community. Finally seeing the bot reply to my commands made all the hard work completely worth it.
